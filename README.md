# Clap ! Ma carrière

Jeu de carrière acteur / réalisateur en un seul fichier (`index.html`), sans dépendance ni serveur.

## Publier sur GitHub Pages
1. Crée un dépôt GitHub et envoie-y `index.html` (et `.nojekyll`, `README.md`) à la racine.
2. Dépôt → **Settings** → **Pages** → *Build and deployment* : source **Deploy from a branch**, branche **main**, dossier **/ (root)**.
3. Après une minute, le jeu est en ligne sur `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.

## Notes
- Les 3 sauvegardes sont stockées dans le navigateur (localStorage), donc propres à chaque appareil.
- Les actus « réelles » sont un instantané du 24 octobre 2026 : le jeu ne se connecte à aucun site.
